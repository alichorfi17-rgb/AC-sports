# 🏋️ AC Fitness — مدربك الشخصي

تطبيق لياقة عربي (PWA) يعمل بالكامل داخل المتصفح ويُثبَّت على الهاتف:
برامج تمارين تتكيف مع هدفك ومعداتك وإصاباتك، أنظمة تقسيم عالمية (PPL، علوي/سفلي، كامل الجسم…)،
تتبع الأوزان والسعرات، تحديات يومية، اختبار مستوى، مدرب ذكي (Gemini)، ووضع ليلي/فاتح بألوان متعددة.

> **الخصوصية:** كل بياناتك تبقى على جهازك. لا خوادم ولا تتبّع. ميزات الذكاء الاصطناعي اختيارية وتعمل بمفتاح Gemini الخاص بك فقط
> (التفاصيل في `privacy.html` و`AI-SETUP.md`).

## 🚀 النشر على GitHub Pages (من الهاتف أو الحاسوب)
1. أنشئ مستودعاً جديداً (مثلاً `ac-fitness`) على github.com وجعله **Public**.
2. اضغط **Add file ← Upload files** وارفع **كل ملفات هذه الحزمة** (بعد فك الضغط) في جذر المستودع، ثم **Commit changes**.
3. من **Settings ← Pages**: اختر **Source: Deploy from a branch**، والفرع **main**، والمجلد **/(root)**، ثم **Save**.
4. بعد دقيقة إلى دقيقتين يظهر الرابط: `https://اسم-المستخدم.github.io/ac-fitness/`
5. افتح الرابط في Chrome ← القائمة ← **تثبيت التطبيق**.

> بعد أي تحديث للملفات: ارفعها من جديد (Upload files تستبدل القديمة). إن ظهرت نسخة قديمة فأعد تحميل الصفحة مرتين.

## 💻 التشغيل محلياً
```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## 📁 الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (واجهة + منطق) |
| `sw.js` | عمل التطبيق دون إنترنت (Service Worker) |
| `manifest.json` + `icon-*.png` | بيانات التثبيت والأيقونات |
| `privacy.html` | سياسة الخصوصية وشروط الاستخدام (أضف بريد التواصل فيها) |
| `AI-SETUP.md` | طريقة تفعيل المدرب الذكي بمفتاح Gemini مجاني |

## ⚠️ تنبيهات
- المحتوى للتثقيف الرياضي وليس نصيحة طبية. استشر طبيبك قبل البدء.
- السعرات المحروقة ومعادلات الجسم تقديرية.
- لم يُحدَّد ترخيص للمشروع؛ أضف ملف `LICENSE` الذي تختاره قبل مشاركة الكود.
